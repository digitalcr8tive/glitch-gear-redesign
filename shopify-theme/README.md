# Glitch Shopify Online Store 2.0 homepage package

This directory contains the production Shopify sections, snippets, assets, and JSON homepage template corresponding to the GitHub Pages presentation.

## Install

Merge these folders into the business's current Shopify theme, then configure the homepage in the Theme Editor. Back up or duplicate the live theme first. The package deliberately excludes a replacement `layout/theme.liquid` so existing app hooks, analytics, localization, customer accounts, global cart drawer, and theme settings remain intact.

## Required Theme Editor configuration

1. Upload the approved horizontal Glitch logo to the header and footer sections.
2. Select the approved woman and man lifestyle images in the hero section.
3. Set the hero buttons to the shop and collections destinations.
4. Select the six collection blocks and optional collection logos.
5. Select the real Featured Drops collection.
6. Leave the countdown end date blank unless an active drop has a verified end date.
7. Assign four Shopify navigation menus to the footer columns.
8. Add only Facebook, Instagram, X, and Etsy URLs.

The four-item benefits strip beneath the campaign banner has been removed from the homepage template.

The bundled banner is original artwork created for this project and contains no recognizable third-party characters or visible eyes.
